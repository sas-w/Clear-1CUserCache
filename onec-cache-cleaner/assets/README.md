# Иконка приложения

`app-icon.png` — исходник, созданный встроенным image_gen.
`../app.ico` — ICO с размерами 16, 24, 32, 48, 64, 128 и 256 px.
При сборке ICO встраивается в Win32-ресурсы EXE; окно извлекает его из самого EXE.
Отдельные файлы изображений пользователю не нужны.

Финальный prompt:

Use case: logo-brand. Asset type: Windows desktop application icon for a utility that clears 1C user cache. Create one polished square app icon: a warm yellow rounded square tile, a simple dark charcoal stack of three cache/database disks, with a small diagonal cleaning brush and a single white sparkle. Bold clear silhouette, very few large shapes, readable at 32px, crisp edges, subtle dimensional shading, professional utility icon. Centered composition filling 85% of image, transparent outside rounded tile. No text, no letters, no numbers, no watermark, no extra objects. Output one square PNG.
