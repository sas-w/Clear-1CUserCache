# Clear-1CUserCache

Небольшая Windows-утилита для очистки локального кэша 1С текущего пользователя.

- Очищает кэш в `Local` и `Roaming`.
- Проверяет запущенные окна 1С перед очисткой.
- Работает без прав администратора.
- Не удаляет `1CEStart`, каталоги лицензий `conf` и `licenses`, файлы `.lic` и список информационных баз.
- Имеет компактный графический интерфейс.

## Запуск

Скачайте `Clear-1CUserCache.exe`, запустите его и нажмите **«Очистить кэш»**.

Перед очисткой закройте все окна 1С. Первый запуск 1С после очистки может занять немного больше времени.
